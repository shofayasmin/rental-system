# Abstract Draft (With In-Text Citations)

House rental operations in many local markets are still affected by unstructured information and subjective decision processes, which can reduce service quality and transaction clarity (Setiawan et al., 2026). Prior studies show that web-based rental platforms can simplify rental search and improve service speed for prospective tenants (Monteverde et al., 2023; Wahab et al., 2025), while online rental management systems are intended to streamline administrative rental tasks (Obse, 2025). Based on this gap, this research develops a web-based house rental management system using Laravel and MySQL to integrate property listing, rental request handling, payment confirmation, contract generation, contract extension, and contextual tenant-agent messaging in one workflow. The system applies role-based access control (admin, agent, tenant), status-based transaction flow, record locking, and payment due-date expiration to reduce conflicting updates and duplicate booking risk. This control focus is aligned with findings that access control remains a critical security issue in web applications (Le et al., 2022). Using a web-based system development approach, implementation is validated through functional and scenario-based testing of key modules. The result is an integrated platform that improves traceability, data consistency, and operational monitoring of rental transactions, while providing structured data for decision support and future analytical reporting.

**Keywords:** House Rental System; Property Management; Rental Transaction; Data Analysis; Web Application
