# Journal Screening Workflow (APA 7, Full-Text Only)

## Rules
- Publication window: 2021-08-01 to 2026-08-31.
- Use only full-text Open Access or legal author preprint.
- Do not keep abstract-only sources for final thesis citations.
- Citation style: APA 7.

## Steps
1. Run queries in Publish or Perish.
2. Export candidates to CSV/RIS.
3. Copy candidates into `journal_screening_template.csv`.
4. For each paper, fill:
- `full_text_access`
- `pdf_local_path`
- `evidence_sentence_verbatim`
- `evidence_location`
- APA in-text and reference format
5. Mark `decision=keep` only if full text is accessible and evidence sentence is recorded.

## Suggested Query Topics
- house rental web-based information system
- property management web application
- rental transaction workflow payment
- role-based access control web application
- dashboard KPI decision support
